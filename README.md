# Satellite Management System

A Spring Boot backend project for managing satellites and missions.

## Features
- Add Satellite
- Get Satellites
- Delete Satellite
- REST APIs
- Layered Architecture

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## API Endpoints

GET /satellites  
POST /satellites  
DELETE /satellites/{id}
